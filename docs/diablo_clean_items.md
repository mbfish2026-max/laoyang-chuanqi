# items 组暗黑残留清理

分支：`clean-items`。负责高05、高06、高07、高13、高15、高16、高18、低06、低01。

## 逐条变更与兼容

| 审计项 | 改动 | 兼容保留与理由 |
| --- | --- | --- |
| 高05 | 商店旧赌博页改为盟重赌石坊入口；旧 `gamble` 调用不扣款、不单独抽取装备。 | 商店货架、回购、旧物品记录不删除；保留函数供旧包装调用。 |
| 高06 | 淬锋按精良7次、稀有10次、极品及以上15次；仅传奇八属性可选。未决候选阻止再次扣费，可保留原词条；触控目标至少44px。 | `rf.n/off/boff/bless` 保留；历史次数超新上限时不截断；数值型历史 rf 转为次数对象。禁止属性的候选折成固定防御，按旧候选结果的战力重算；原结果封存在 `cqOriginal`。 |
| 高07 | 全局兼容品质字典统一普通/精良/稀有/极品/套装；上古、至臻沿用 anc 标记。赌石结果修正为 q3/q4/q5，对应精良/稀有/极品；回收复用全局字典；仓库加入上古/至臻筛选。融合品质显示使用名称。 | 稀有属于本次明确允许品质，保留 q4。旧 q0/2→普通，q7→稀有，q8→极品，只在迁移层映射。融合保留主体已付费次数、祝福及待选结果。 |
| 高13 | 掉落提示 q5 改为全局极品名称，新增上古/至臻提示与优先级；不再将旧玩法字段识别为新掉落种类。 | 旧掉落记录原样存档；显示时将含禁止词的历史装备名归为“旧版装备”，不恢复旧玩法。 |
| 高15 | 祖玛、赤月、魔龙及圣战/法神/天尊套装改为固定攻击/魔法/道术/防御/魔御奖励；移除吸血、1.5倍伤害、追加斩击、叠火墙、冷却减半与溅射钩子。固定主属性接入技能/攻击与魔御减伤。 | 套装ID、部件身份、收集记录、首领300杀保底与待领取装备保留。其他套装奖励也过滤为固定八属性。 |
| 高16 | 新增独立 `cqCleanVersion=2` 标记，旧 v1 已迁移装备也升级。`allMods` 不再注入 `cqLegacy`，最终只输出允许属性。百分比本地攻防先折固定值，防护属性折魔御，其余战力缺口补固定防御。无基础防御的首饰同样按实际固定防御计战力。 | 装备UID、强化、锁定、容器位置和进度保留；`cqOriginal/cqOriginalName/cqLegacy` 只供审计。遍历角色、英雄、各仓库、待领取及账号容器，不受角色旧全局迁移标记短路影响。迁移为纯对象复制且幂等。 |
| 高18 | 新随机池仅攻击、魔法、道术、防御、魔御、准确、敏捷、幸运；固定定义、底材附加属性及上古额外属性过滤；不再把禁止词条自动改为新生命词条。 | 允许既有固定生命/魔法上限及区间端点字段，随机极品与淬锋池不生成生命/魔法上限。特戒原始记录仍能核对，不通过有效属性表注入旧特殊字段。 |
| 低06 | `items.js` 品质生成改为一次抽取传奇品质，移除运行中的 D2 品质比率/MF递减公式及无用辅助函数。 | 保留 `qualityChance/qRoll` 兼容接口和生成函数骨架，供现有调用使用；不重写其他组的掉落进度与战斗模块。 |
| 低01 | 核查后保留旧数据文件，不贸然删除。 | `data_items.js` 仍定义 `ITYPES/AF` 等结构，后续传奇表原地清空/覆盖；`cq/data_cq.js` 在覆盖前捕获 `CQ_D2_SLOT`，迁移依赖旧底材ID→部位映射。未确认整体无依赖，故保留脚本与映射。 |
