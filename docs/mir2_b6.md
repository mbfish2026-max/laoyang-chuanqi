# 第6块：龙帝结构借鉴（第三次发布）

本块采用1.80英雄合击/老羊的固定属性量级，不引入龙帝装备线、心法、百分比淬炼、属性点、技能点或付费玩法。没有新增或拷贝图片素材，沿用已有控件样式。

## 装备位淬炼

角色页「部位淬炼」，武器、衣服、头盔、腰带、鞋子五部位。蛟龙/蟠龙/应龙三阶，每阶十星。存档为 `S.slotRefine[slot]={tier:0..2,star:0..10}`，未强化为0阶0星，阶末10星保留显示，下一星进入下一阶。换装、卸装不清空；角色之间独立。

每星固定增加1点：武器增加当前职业攻击上下限（战士），或魔法/道术上下限（法师/道士，按现有装备换算进入主动伤害技能：法师每点+3伤害，道士每点+1伤害，不作用于英雄）。衣服/头盔增加最终防御；腰带/鞋子增加受魔法攻击时的固定减伤（魔御）。全部满星合计主属性30、防御60、魔御60，不乘百分比。不替代原装备强化 `it.en`。

必定成功，无掉星。第n颗已有星之后的下一次花费1000×(n+1)金币，以及1+floor(n/10)淬炼精华（每部位总计465000金币、60精华）。精华保存在 `S.refineMat`，首领击杀固定给1个（同怪不重复），红龙圣地通关给20个。缺字段旧档按0初始化，不扣现有属性。

## 三合一融合

背包「三合一融合」。三件同名、同底材、同品质的普通装备；锁定、上古、套装、暗金/更高品质、特殊物品不作为原料。阶梯为q1/2→q3魔法→q4稀有→q5暗金（只提升品质，不生成暗金专属命名或额外装备线）。每次2000×原q金币、3残骸精华。

列表中显示的第一件为主体：保留uid、底材、名称、原词条和已采用的淬锋结果，强化取三件最高 `en`，额外固定攻击上限+1。其余两件消耗，主体留在背包原位置。主体祝福属性、祝福候选、淬锋候选及次数清空；其他两件的淬锋/祝福不转移。部位淬炼在角色上，完全保留。材料不足时无任何消耗。

## 淬锋内的龙魂祝福

仍从商店「重铸」进入原淬锋弹窗，不另设系统页。q≥3均可祝福，原先无可重铸词缀的高品质装备也可进入。沿用 `it.rf`：`n`为淬锋/祝福共用次数，`bless`为已采用的祝福，`boff`为尚未选择的候选。

一次随机生成1–3条不重复属性作为一组候选，可以「保留旧祝福」或「采用新祝福」，无自动替换。候选关闭后保留，不重复扣费。候选池为攻击上限、魔法、道术、防御、魔御、准确、敏捷、幸运，前七者随机+1–2，幸运固定+1；不含百分比、技能等级或D2词缀。已经锁定的淬锋键不进入祝福池，祝福键不供旧淬锋锁定，防止交叉覆盖。

按品质上限魔法7、稀有10、暗金/套装/上古/更高15次；沿用费用5000×(n+1)²金币和5×(n+1)残骸精华。旧档已超过新上限的次数不回退，已有属性和待选候选仍保留。两种候选不可同时生成，需先处理当前候选。融合时移除祝福实际增量并清空次数，保留已采用的原淬锋结果。现有一次性淬锋特效保留，祝福没有循环特效。

## 红龙圣地

地图页入口，22级解锁，北京时间自然日每日1次，进入即扣次数，死亡/超时/退出不退次数。单人挂机五阶段，目标生命1200/2400/3600/4800/6000，每阶段180秒游戏时间；非墙上时间。每秒攻击取职业装备伤害区间均值、武器淬炼、等级×2，至少1；每秒承伤为max(1,8+阶段×4−(最终防御+淬炼魔御)/80)。这是一套独立副本遭遇，不改原地图首领。

进入时读取角色最大生命，连续五段不自动回满；自动开启挂机。副本期间暂停普通地图主循环，阶段战斗在模态窗口显示生命、目标生命、阶段及剩余时间；关窗继续战斗，可从入口重新查看。挂机关闭则暂停，离线不推进，重载恢复保存的状态。生命≤0失败，目标击杀推进（同刻死亡优先失败），限时内未击杀则超时。死亡不调用普通地图死亡逻辑，不掉装备；成功立即发20精华且不能重复领取。状态存于 `S.redDragon`，每秒和阶段变化保存。
