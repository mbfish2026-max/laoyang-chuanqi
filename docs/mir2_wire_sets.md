# R03 中后期套装闭环

基于 b28daa3；独立实现为 `cq/mir2_sets.js`。index 在 CQMir2Equip.install() 后、mir2_b6 前加载。浏览器自动安装；无 UI VM 先安装装备，再调用 CQMir2Sets.install()（cq_harness 已接线）。安装幂等，未修改 classes.js、bossloot.js、原首领属性或原掉落池。未引入新美术。

## 内容与身份

- 祖玛三职业：绿色项链/骑士手镯/力量戒指、恶魔铃铛/龙之手镯/紫碧螺、灵魂项链/三眼手镯/泰坦戒指；补黑铁头盔供四部位配装。现有左右手镯分别占 shield/gloves，均可计件。2件攻速+10、4件增强伤害+10%/生命+30，沿用既有 edmg 结算。
- 赤月四件 `chiyue_zs/fs/ds`：复用圣战/法神/天尊的头盔、项链、手镯、戒指传奇属性；2件生命+12、4件生命+18/吸血3%。近战用既有 ll；直接法术命中补实际扣血3%，不重复加近战吸血，不给持续伤害额外吸血。
- 雷霆/烈焰/光芒保留已有内容ID与部件属性；2件生命+12、4件生命+18、6件魔法值+15、本职业直接技能、施毒/炮台/火墙与主角召唤物伤害×1.5。普攻、英雄及其召唤物不借用主角套装。
- 圣战/法神/天尊沿用已有ID及单件属性、2/4/6件生命/魔法值奖励，6件分别增加烈火一次50%追加斩（独立命中判定）、火墙两层独立到期且冷却减半、神兽命中对另外最多2个目标造成35%基础伤害溅射（按各目标抗性正常结算，不把已放大的结算伤害再乘一次全局倍率）。追加伤害不再次耗蓝、加熟练度、施放技能或播特效。
- 赤月与机制套是不同套装身份，不能互相计件；同名是复用传奇部件，不伪造原版数值。所有2/4/6件奖励均为本游戏原创。
- 兼容旧 `zuma` 占位套装与既有 shengzhan/fashen/tianzun 装备；不重写实例 uid、强化、淬锋、锁定或旧等级。新增内容ID `set_chiyue_<cls>_<slot>`、`set_zuma_<cls>_helm`；genItem 外层按 set+base 修正同名物品身份，精确生成优先指定ID。

## 钩子

包装 clsCast 仅建立主角施法上下文，finally 恢复；hitMon 加六件技能倍率、法术吸血及神兽溅射（绕过自身包装，无递归）。CLS_TY.hit/burn/pois/turret/aoe 消费对应套装效果；火墙在 burn 对象记录 cqWalls，每层保存到期 GT 与快照 dps；现有 classes.js 的持续伤害 tick 读取 dps。acFeasible/clsCdLeft 使法神自动火墙按半冷却补层。更换装备立即影响新的攻击；已施放持续伤害保留施放快照至到期。

count/active 只读主角 S.eq 的有效槽位且校验职业；英雄独立套装机制不在本批范围，沿用其既有装备与伤害预算。机制不增加属性点或技能点。

## 掉落、保底与图鉴

独立包装 rollTC：祖玛教主→祖玛三职业，赤月恶魔→赤月三职业，魔龙教主→雷霆/烈焰/光芒，暗之牛魔王→圣战/法神/天尊。原池原样保留；每杀额外2.5%尝试一次套装掉落（原创概率，非历史原版掉率）。不限制难度，等级/职业穿戴仍走原系统。

每个对应首领累计300杀，额外给本职业一件未收集部件；收齐后轮转，不重置累计次数。击杀数、已见内容ID和满包待领取分别存 S.mir2Sets.kills/seen/pending，自动跟随角色存档。保底按既有 bagFits/BAG_SZ 判断容量，满包保留物品实例，图鉴领取后 save()。普通随机掉落继续原满包处理。记录以 rollTC 结算为击杀口径，不补算接入前历史总击杀。

角色页「套装图鉴」展示部件、穿戴件数、原创奖励、首领累计杀数与距保底次数；「领取保底」领取待存物品。详情补穿戴件数与机制文本。图鉴390×844限定视口高度、内部滚动，按钮最小44px/不换行，沿用空白关闭。
