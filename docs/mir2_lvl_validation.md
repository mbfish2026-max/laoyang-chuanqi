# 第 5 块：等级、经验与转生验收

范围：1.80 英雄合击规则、1.76 基础经验表；等级 60 封顶。未引入内功、心法、属性点、技能点或宝石镶嵌。未修改首领基础生命、攻击、防御。

## 经验与成长

`data.js` 保存资料包 `systems.md` 的 1–50 级「升下一级经验」原表，接口 `xpNeed(L)` 仍返回到达 L 的累计经验。51–60 的单级经验从 42 亿按每级 ×1.25 外推；61 是有限的经验展示端点，角色不能升到 61。

50 级后显示等级压缩旧 50–99 的成长：`50 + floor((L-50)×4.9)`，60 级对应旧 99 级。生命、法力、属性、命中、战士等级武器、职业平衡插值、召唤物与英雄成长同步使用成长等级。技能与新装备的原版需求仍用显示等级。怪物等级、首领数值没有跟随显示等级降低。

击杀经验按当前新旧成长区间的经验差换算，任务的本级百分比经验继续按新表计算。保留浮点经验到掉落结算阶段，避免先取整破坏血月 ×1.5 经验关系。

## 存档与转生

存档版本 6，另有 `cqProgress` 幂等标记。迁移保存原等级、经验快照及原等级下限；旧 70 级映射显示 55 级，旧 99 级映射 60 级。旧属性固定奖励保留，旧点数与洗点道具按迁移前等级折金币，旧装备需求随旧等级同步映射，迁移不重复发奖励。计算成长有重入保护，防止同一等级被重复压缩。迁移异常由既有事务回滚处理。

60 级后的经验进入 `rebXp`，跨到 60 级时的溢出经验也保留；英雄在主角满级后仍可追级。最多十转，每转战士固定力量 +1、体力 +1，法师／道士固定精力 +1、体力 +1；无可分配点数，等级与装备保留。首转需要第 60 级外推单级经验，以后每转需求增加首转的 25%。已有转生固定奖励不重发；转生战力估值按次数除以10归一化，十转合计最多10%，不会把每一转误当作10%。

满级后角色顶栏与卡片战场的经验条改显示转生进度，转生后归零，十转后显示已满。角色页首屏用转生入口替换已停用的属性点按钮，四个操作按钮均至少44px；弹窗按钮 88×44 CSS px、文字不换行、点击遮罩关闭。旧魂阶菜单已替换为转生页，旧档已分配魂阶属性继续有效（含满级后的经验加成），但停止产生和分配旧自由点。无新增动画或图片。
