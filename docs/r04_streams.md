# R04 九流派

九流派入口在技能页。选择会保存当前角色的流派、四格技能与自动顺序；不会学会技能、消费技能书或改变技能等级。未选择流派的旧档保留原有四格与自动设置。预设后仍可调整四格和自动顺序。

主技能按辅助技能已学等级每级额外加强 2%，不削减其他技能；法师宝宝增强其生命/攻击系数。雷电、火墙、火符补齐辅助协同。自动施放按当前可用的预设攻击顺序检查，冷却、法力、目标和持续效果仍走既有可行性；核心不可用时回退到已有智能选择。

骷髅辅助使用独立的骷髅/神兽持久化记录，保留项圈与死亡恢复规则。火墙随魔法与辅助技能成长，持续伤害不重复播放施法特效。瞬息移动仅在当前战场空格间移动，不重置首领。困魔不控制首领、精英或等级过高目标；心灵启示标记目标并保留原降防收益。集体隐身、幽灵盾、神圣战甲术在有效期内保护召唤物，过期无残留。英雄白名单补入魔法盾和隐身术，继续走原英雄预算与技能书规则。

战场容器的定位覆盖了后加载样式的冲突，避免四格技能被零高度的容器裁掉。未新增素材。
