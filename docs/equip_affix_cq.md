# 装备属性对照与迁移规范

以 1.80 英雄合击、1.76 基础表为准；未知白金/星王属性明确标为本游戏设计值。

| 原暗黑属性 | 传奇新掉落 | 旧档处理 |
|---|---|---|
| 伤害/增强伤害% | 攻击 x-y，极品攻击上限 +N | 保留旧标量于 cqLegacy，不重复计算 |
| 魔法/道术标量 | 魔法/道术 x-y | 原值保留，端点独立输出 |
| 防御/增强防御% | 防御、魔御 x-y | 原值保底 |
| 元素抗性、吸血吸蓝 | 不再生成 | 隐藏兼容补偿保持原实效 |
| +技能等级、施法速度 | 不再生成 | 保留兼容补偿 |
| 前后缀名称 | 底材名，极品 +N | 改显示名，不改 uid |
| 准确/敏捷/幸运 | ar/dex/luck；诅咒 curse | 恒等保留 |
| 生命/魔法值/攻速 | life/mana/ias | 恒等保留 |
| 强化 | en +1～+9 | 不改失败/不碎装规则 |

装备区间用 cqRange，附加固定点用 cqBest；区间不塞入旧标量累加器。allMods 暴露端点且旧标量只加一次；战斗沿用旧有效属性，避免更换数值体系改变挂机节奏。迁移保留原 dmg/def 与全部有效修饰，禁止静默丢弃未知内容。新附加仅生成固定属性点；不生成宝石或凹槽。

套装 2/4/6 件奖励是本游戏原创，祖玛 legacy 原奖励保留。白金、星王及资料缺失部件用设计值。持久为资料标注值，挂机不磨损。

原版点数与旧引擎单位的本游戏换算：新装备准确 1 点→引擎准确 2，攻速 1 点→引擎攻速 5%；仅在 allMods 适配，详情仍显示传奇点数。旧档 cqMigrated 装备保持原引擎数值，绝不二次放大。极品生命/魔法值为固定 +5～15，攻击上限 +1～5、防御 +1～4；精良 1～2 条、稀有 3～6 条原抽取预算保留，名称统一去掉前后缀。

特戒触发率、防护占比等沿用 M1 本游戏设计值；资料表只提供基础属性，不把设计触发率称为官方公式。防御戒指/火焰戒指的道术/魔法来自底材 1–2，不再在暗金修饰里重复加一次。

幸运极品仅武器/项链；攻速极品仅武器/项链/戒指。新魔法、道术区间分别以每点 3/1 点伤害接入伤害/召唤，并计入职业战力，替代移除的技能等级词缀。固定暗金附加使用 cqBonus，随机极品使用 cqBest，基底与两类增量只加一次。魔御/幸运的共享消费片段及测试加载器见接线文档。
