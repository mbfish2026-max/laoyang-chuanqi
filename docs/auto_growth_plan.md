# 自动成长方案（auto_growth_plan）：取消属性点 / 技能点

> 需求：升级不再给属性点、技能点；照原版《传奇之旅》（`/workspace/chuanqi/web-replica/`）：**属性按职业+等级自动成长**；**技能只靠技能书学会/升级**（等级要求、熟练度）。
> 调查基于 master `d5d3d04`（2026-10-22）。本文为方案，未改代码。数值表由 node 跑本游戏 `calc()` 得出（脚本见 §5.3，放在 /tmp，未入库）。

## 1. 原版规则（带出处）

### 1.1 属性成长
- `js/game.js:60-65 profCfg()/calcAttr()`：`maxhp=ceil(hp+L*g_hp)`、`maxmp=ceil(mp+L*g_mp)`，攻击/魔法/道术/防御的 min/max 各 `ceil(base+L*g_x)`；再叠加装备、强化、被动技能（`:77` 被动「攻击 +N 点」直接加攻击）。
- `js/game.js:88-91 addExp()`：升级只 `level++` 并回满血蓝，**没有任何点数**。
- 成长系数 `assets/config/profession.txt`（1001/1002/1003）：

### 1.2 技能书规则
- `js/game.js:96-110 learnFromBook(itemId)`：
  1. 书 → 技能（`skill.booknum[0]`）；职业不符拒绝（`job!=prof`）。
  2. 下一级行 `next=skillRow(base,cur+1)`，无则「技能已满级」。
  3. **等级要求** `r.level >= next.slevel`。
  4. **熟练度**：已学（cur>0）时须 `skills[base].exp >= 当前级.exp`。
  5. **书数量**：消耗 `next.booknum[1]` 本同名书。
  6. 成功后 `{lv:cur+1, exp:0}`（熟练度清零）。
- 熟练度来源：主动技能每次施放 +1（`game.js:144`）、被动触发 +1（`:146`）、治疗 +1（`:241`）、自身 buff +1（`systems/buff.js:65`）；**技能丹** +100/个（`systems/smith.js:69-72`）。
- 发书：1 级新手礼包附送本职业 slevel≤35 的全部 1 级书（`systems/core.js:91-104`）；出生技能 法师火球、道士召唤骷髅（`core.js:106-110`）。
- `assets/config/skill.txt`：每技能 **9 级**；`slevel` = 1 级需求 + 3×(级-1)；书数量 1,2,3,5,10,20,30,40,45；熟练度 600,1000,3000,5000,10000,20000,30000,40000,50000（道士部分技能更高）；`pagenum` 书页 0,50,100…6400（本地复刻未用）。
  例：基本剑法 L7/10/13…31；攻杀剑法 L17…41；火球 L7…31。

## 3. 新规则

### 3.1 属性：按职业×等级自动成长
仍用 `S.at` 四维（`calc()`、装备需求、`late.js` 主属性加伤都依赖它，改动最小），但 **S.at 不再存档，由 `clsAutoAt(cls,L)` 推导**：
`S.at[k] = CLS_DEF[c].at[k] + floor(GROW[c][k] × (L-1))`

| 职业 | 力量 str | 敏捷 dex | 体力 vit | 精神 ene | 合计/级 |
|---|---|---|---|---|---|
| 战士 zs | 2.8 | 0.3 | 2.5 | 0 | 5.6 |
| 法师 fs | 0 | 0.3 | 2.5 | 2.8 | 5.6 |
| 道士 ds | 0.2 | 0.3 | 2.5 | 2.7 | 5.7 |

设计说明：
- 方向对齐原版：战士吃力量（攻击）+体力（生命高）、法/道吃精神；道士带一点力量（原版道士 g_maxzs 0.5）；全职业带敏捷（原版防御/准确随级成长）。
- 量级：现自动加点 5 点/级，新表 5.6–5.7 点/级（多出部分主要进敏捷，换来防御/命中），**各项均 ≥ 现自动加点**（见 §3.3）。
- 可选「原版味」展示：角色页显示 攻击/魔法/道术 区间 = 现 `ST.wmin–wmax` / 技能伤害，不额外加原版 hp/g_hp（与 calc 双计）。是否改为直接用 profession 表见 Q1。

### 3.2 技能：只靠技能书
保留老羊技能等级上限 20（cls_*.js 数值按 1–20 写），按原版结构改造 `CS.bookLearn`：
1. **学会**：本职业 1 级书，`S.lvl >= s.r`（技能需求等级，原 `canLearn` 的前置技能保留）。
2. **升级**：`n → n+1` 需要：`S.lvl >= slevel(n+1)`、熟练度 `exp >= need(n)`、消耗 `book(n+1)` 本同名书；成功后 exp 清零。
   - `slevel(n) = s.r + ceil(1.1×(n-1))`（原版每级 +3 级、9 级上限；老羊 20 级上限压到每级 +1.1，使主技能 Lv40 正好可满 20）。
   - `book(n)`：1,1,1,1,2,2,2,3,3,3,4,4,5,5,6,6,7,8,9,10（原版 1→45 曲线缩放，可调，见 Q3）。
   - `need(n)`：施放次数；建议 `need(n)=ceil(60×n^1.5)`（原版 600→50000 是 1.3 秒攻速 + 9 级；老羊施法频率需职业开发按 cls_sim 实测调）。
3. **熟练度来源**：每次施放/被动触发 +1（职业引擎 `acCast`/被动触发处）；多余的同名书（已满级前）可「研读」= +熟练度（原版技能丹 +100 的替代）；福利/商店「技能丹」可选。
4. **自动**：`S.autoSk` 语义改为「挂机自动用书升级」（已有 `bookAutoUse`），熟练度够、书够、等级够即升。
5. 发书：照原版新手礼包，**创建角色时给本职业 r≤35 技能的 1 级书**（`core.js:91-104`）；`CQ_BAL.book` 掉率按 §3.3 拉齐。
6. 主动技能被动加成、前置、互斥（`s.g`）规则不变。

### 3.4 旧存档迁移（`clsMigrate` 同位置，标记 `S.agV=1`）
1. `S.at` 直接按 `clsAutoAt(cls,S.lvl)` 重算；`S.sp` 清零（不退任何东西，§3.3 保证不弱）。玩家手动加歪的档（如全体力）会变化，需提示一次「属性已改为自动成长」。
2. `S.sk` **原样保留**（含 >slevel 的等级不降）；每个已学技能补 `S.skx[id]=0` 熟练度；`S.kp` 清零（剩余未用点数：可按 1 点 = 1 本「通用技能书页」补偿，见 Q4）。
3. `S.resp` 持有的洗点药水折金币（按 `respPrice` 当前价）；删除 `S.autoAt`；`S.autoSk` 保留为「自动用书」。
4. 迁移幂等；云存档老客户端读到 `S.sp>0` 也不会出问题（只是多显示点数），但须与 UI 改动同版本发布。

## 5. 附录

### 5.2 开放问题
- **Q1** 属性是否完全换成原版 profession 表（生命/攻击/防御直接随级，弃四维）？那要重写 `calc()` 和装备力量/敏捷需求，工作量大，本方案保留四维。
